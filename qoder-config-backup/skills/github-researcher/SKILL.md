# GitHub研究员

自动在GitHub搜索、分析、学习优秀项目，将最佳实践应用到自己的项目。

---

## 核心能力

### 1. 自动搜索相关项目

```
你说：我想做一个电商数据监控平台

我自动：
1. 搜索GitHub：
   - "ecommerce price monitoring"
   - "电商爬虫 价格监控"
   - "product price tracker"
   - "competitor price monitoring"

2. 筛选优质项目：
   - ⭐ Stars > 100
   - 📅 最近有更新
   - 💬 活跃的Issues讨论
   - 📖 文档完善

3. 分析代码结构：
   - 技术栈选择
   - 架构设计
   - 核心算法
   - 数据库设计

4. 提取可复用模块：
   - 数据采集逻辑
   - 价格对比算法
   - 通知系统
   - 数据可视化
```

### 2. 学习优秀思路

```
找到优秀项目后，我自动分析：

✅ 这个项目为什么Stars高？
   - 解决了什么痛点？
   - 有什么创新功能？
   - 用户体验好在哪里？

✅ 技术实现有什么值得学习？
   - 用了什么技术栈？为什么？
   - 架构设计有什么亮点？
   - 性能优化怎么做到的？
   - 反爬对抗有什么技巧？

✅ 可以应用到你的项目吗？
   - 哪些模块可以直接复用？
   - 哪些思路可以借鉴？
   - 需要做什么修改？
```

### 3. 应用到你的项目

```
分析完成后，我自动：

1. 推荐最佳实践：
   "我找到了3个优秀的电商监控项目，
   其中Project A（2.3k Stars）的价格对比算法特别好，
   建议应用到你的项目。"

2. 自动实现：
   "我帮你把Project A的核心算法移植过来，
   并且根据你的需求做了优化。"

3. 解释效果：
   "移植完成后，你的项目可以：
   - 自动监控1000+商品价格
   - 价格变化实时通知
   - 历史价格趋势分析
   你觉得怎么样？"
```

## 搜索策略

### 1. 中文项目优先

```
搜索关键词：
- 中文关键词："电商爬虫"、"价格监控"、"数据采集"
- 英文关键词："web scraping"、"price monitoring"
- 混合搜索："爬虫 Python 电商"
```

### 2. 筛选标准

```
⭐ Stars > 100（说明有价值）
📅 最近3个月有更新（说明活跃）
💬 Issues有回复（说明社区活跃）
📖 有README和文档（说明质量好）
🔧 有完整的代码结构（说明可以学习）
```

### 3. 分析维度

```
分析内容：
1. 项目结构 — 文件组织方式
2. 技术栈 — 用了什么框架/库
3. 核心功能 — 主要实现什么
4. 代码质量 — 命名规范、注释、模块化
5. 性能优化 — 缓存、并发、数据库优化
6. 安全性 — 反爬对抗、错误处理
7. 部署方式 — Docker、脚本、云函数
```

## 自动学习流程

### 第1步：搜索

```
搜索关键词生成：
- 你的项目类型 + "开源"
- 你的核心功能 + "implementation"
- 你的技术栈 + "best practices"
- 你的行业 + "project"
```

### 第2步：筛选

```
自动筛选：
✅ 去掉fork的项目
✅ 去掉文档不全的
✅ 去掉很久没更新的
✅ 去掉Stars太少的
✅ 保留技术栈匹配的
```

### 第3步：分析

```
深度分析Top 3项目：
1. 为什么这个项目受欢迎？
2. 核心技术是什么？
3. 架构设计有什么亮点？
4. 代码质量如何？
5. 有哪些可以学习的？
```

### 第4步：应用

```
应用到你的项目：
1. 哪些可以直接用？
2. 哪些需要修改？
3. 哪些只供参考？
4. 自动生成代码/文档
5. 集成到你的项目
```
